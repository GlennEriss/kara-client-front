## 📖 Guide de lecture

### Pour commencer
1. Lire `general/WORKFLOW.md` pour comprendre le workflow
2. Lire `general/CONTRIBUTING.md` pour contribuer au projet
3. Consulter `architecture/ARCHITECTURE.md` pour l'architecture

### Pour développer
1. Consulter `design-system/` pour les standards UI
2. Lire `firebase/FIREBASE_SETUP_CHECKLIST.md` pour configurer Firebase
3. Voir `tests/TESTS_ARCHITECTURE.md` pour les tests

### Pour un module spécifique
Consulter le dossier correspondant dans les modules métier.
